# 事前点検の手順

禁止と境界は [AGENTS.md](../../AGENTS.md) に従う。このファイルは手順だけを持ち、AGENTS.md の境界を緩めない。矛盾したら AGENTS.md を優先して停止する。

## 目的

凍結前の `docs/current-task.md` が、境界データでも判定でき、否定条件を持ち、既存の挙動と矛盾しないかを見る。

業務上の意味の正しさは見ない（祥が停止で見る）。

## 起動

祥が指示したときだけ行う。`/prepare-f` の後、凍結commitの前に行う。

## 入力

- `docs/current-task.md`（未commit）
- repoの現物（コード・完了済みFの挙動）

## 禁止

- ファイル変更
- Git変更
- Notionの読み書き

## 観点

0. 本数：A（出るもの）が8本を超えていたら、観点1〜3を点検せず「分割」で差し戻す。
1. 判定可能性：条件ごとに、境界データ（LO空・drop空・新規ラン・法規0件・前例なし）で○×が決まるか。
2. 否定条件：「出てはいけないもの」が番号付きであり、主要な出力に対応しているか。
3. 整合：条件同士／既存コードの挙動／やらないこと と矛盾しないか。根拠はファイルと行で示す。

## 出力（固定）

1行目は AGENTS.md の「手順の索引」どおり「読んだ手順：docs/procedures/precheck.md（版：<版>）」とし、その後に次だけを書く。

```
判定：OK／NG
```

NGのときは、1件ずつ次を書く。

```
- 条件番号：
- 観点：0〜3のどれか
- 根拠：ファイル:行（current-task.md の該当行、矛盾する既存コード・既存の挙動の行）
- 何が決まらないか：
```

- 観点0に当たった場合は、この1件だけを書く（条件番号：全体、何が決まらないか：分割）。
- 直し方は書かない。
- OKのときは判定だけを書く。
