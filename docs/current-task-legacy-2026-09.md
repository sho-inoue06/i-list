### 保存形（版2）
```
{ schemaVersion: 2, runs, regs(全行 rid 付き), cert: [{ runKey, rid, ck, planned }], decisions, bases, sameness }
```
- `cert` は 型式ラン(`run.key`) × 法規行(`reg.rid`) のレコード配列（`decisions`・`sameness` と同じ持ち方。連結キーは作らない）。
  `ck`＝管理番号（認可番号とPACT番号を区別しない1欄）、`planned`＝取得予定（器だけ。画面からは常に false、判定にも使わない）。
  レコードが無い＝番号なし・予定なし。画面で番号を空にすると（予定が無ければ）レコードごと消える。
- **旧版のアプリが版2のファイルを開くと `cert` が配列なので読込を拒否する**（黙って読み違えない）。

  付け先の無いものは破棄・予定は false・空文字の番号もそのまま）。知らない版は拒否。
- サーバDB：`cert_run(runKey, rid, ck, planned, pos)`・`regs.rid` 列・`meta(schemaVersion)` を追加。PUTは版2だけ受け付ける。
  **旧 `cert` テーブルは消さずに残し、読み書きしない**（移行元）。旧DBはGETで旧形式のまま返し、フロントが移行して直後の自動保存で版2へ書き戻す。
