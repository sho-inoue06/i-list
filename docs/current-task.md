## 成果識別子

F-31　Excel取り込みの共通仕様を整え会社側へ引き継ぐ

## 目的

指定装置等一覧（Excel）から型式ランごとの認可番号を読み取り、人が確認画面で確かめてからIリストへ反映できるようにする。対象は単体HTML版。

## 対象範囲

- 単体HTML版に、ダミーxlsxの選択 → プロジェクトの指定 → 解析 → 確認画面 → 反映、の流れを足す
- 検証用の完全ダミーのデータ（JSON）とダミーxlsxを新しく作る（公開様式を抽象化した形でゼロから作る）
- 実ファイルのシート・認可番号と備考欄の列位置・備考欄の実書式から型式を読む方法は、今回決めない（実ファイルを扱う側で決める引き継ぎ事項）。今回は下のダミーExcelの列の形だけを読む

### 前提（データの形）

- 法規行のID欄は「R{規則番号}-{シリーズ}」の形で書く（例：R156-01、R13H-00。規則番号には英字が混じる）。この形でない法規行は取込の対象にならない
- 認可番号は「E43*156R01/00*1234*00」の形で、「156R01」の部分から規則番号（156）とシリーズ（01）を読む
- 同じ規則でシリーズ違いの法規行は別の行として並ぶ（例：R156-00 と R156-01。規制日が違うため）
- 取り込むファイルの単位はプロジェクト。どのプロジェクトのファイルかは人が画面で指定する。ファイル名からは判断しない
- 型式ランは「指定したプロジェクトコード × 型式」で決まる
- ダミーExcelの列（公開様式を抽象化した形）：認可番号／対象型式（型式を「,」または「、」で区切って並べる）／未使用列。1行＝1装置

## 完成条件

A＝出るもの。

1. A1　ファイルを選びプロジェクトを指定すると、確認画面にそのプロジェクトコードが出る
2. A2　読めた行が「法規行／認可番号／型式ラン」で1行ずつ確認画面に出る。1装置が複数の型式に当たるときは、型式ランごとに展開される。対象型式の一部だけが指定プロジェクトに無い（または型式ランが1つに決まらない）ときは、残りの型式の分だけが読めた行として出て、その型式の分だけがA4へ出る（装置の行ごとは弾かない）
3. A3　法規行は次の当て方で決まる。番号と規則番号が同じ法規行のうち、(a) シリーズが番号と同じ行→入れる。(b) シリーズが番号より古い行→入れる。確認画面のその行に「01で取得」のように番号のシリーズを示す印が出る。(c) シリーズが番号より新しい行→入れない。例：R156-00 と R156-01 の2行があり番号が01なら、両方の行に同じ番号が出て、R156-00 の行にだけ印が付く
4. A4　読めなかった行は、読めた行とは別の枠に理由つきで出て、件数が出る。件数の数え方：装置の行ごとに1件＝認可番号が空／形として読めない／1セルに番号が複数／対象型式が空／同じ規則番号の法規行が無い／入れられる法規行が無い（これらはその装置の行から1行も読めた側へ出ない）。型式ごとに1件＝型式が指定プロジェクトに無い／型式ランが1つに決まらない。型式ラン×法規行ごとに1件＝同じ型式ラン×法規行に違う番号が2つ以上当たる。理由の一覧：認可番号が空／認可番号の形として読めない／同じ規則番号の法規行が無い／入れられる法規行が無い（どの行も番号より新しいシリーズ）／対象型式が空／型式が指定プロジェクトに無い／型式ランが1つに決まらない／1セルに番号が複数ある／同じ型式ラン×法規行にファイル内の違う番号が2つ以上当たる（この場合はどれも入れない）
5. A5　読めた行は、既存データとの関係で「追加（セルが空）／既存と同じ／既存と違う」に分かれて出る。全角半角・前後の空白だけの差は「同じ」
6. A6　「反映」を押すと「追加」の行だけ、その型式ラン×法規行の認可番号に番号が入る。「既存と同じ」「既存と違う」の行は既存のまま。帳票のセルの表示は既存の規則で決まり、変えない（例：LOが入っていて要否が要のセルは実績ありになる。LOが空のセルは判定不能のまま、要否が否のセルは否のまま）
7. A7　反映を押さずに閉じる、または解析に失敗する（xlsxでない・壊れている）と、帳票とデータは取込前と同じ
8. A8　反映後に保存したHTMLとJSONを開き直すと、反映した番号が同じセルに残っている

## 出てはいけないもの

B＝出てはいけないもの。

1. B1　読めなかった行が、読めた行の側に並ぶ。または空の番号で反映される
2. B2　対象型式に書かれていない型式ランへ番号が入る
3. B3　指定したプロジェクト以外の型式ランへ番号が入る
4. B4　「反映」を押す前に、帳票の実績（●）が変わる
5. B5　既存の番号が書き換わる、または消える（Excel側が空欄でも消えない）
6. B6　番号より新しいシリーズの法規行へ番号が入る
