## 成果識別子

F-42　人の対象外判断で取得予定（○）が隠れる

## 目的

②適用（人の対象外判断）が③予定（○）を書き換えないようにする。従来の「人の判断が対象外なら○を隠す（入力不可、決定表へは予定なしで渡し、保存値は保持）」という規則を覆す。

業務の意味は判定の4つの軸による：①日程・②適用・③予定・④実績。取得義務＝①要∧②適用あり。③予定（○）は人が入れ、④実績は認可番号で機械が決める。③④は①②に左右されない。対象外でも取得することがあり、取る・取ったは管理する必要がある。

今の不具合：対象外のセルでは○の欄が出ず、付けも外しもできない。○を付けてあったセルでも決定表へ「実績なし＋予定なし」で渡り、車両申請は「未計画」になり、危険一覧の「計画済み」の印が消える。保存値の planned: true は残るため、JSON・データ入りHTMLでは「予定あり」なのに画面では見えず外せない（別情報の混入と、蓄積データの可搬性の破れ）。原因の箇所は standalone/cert-status.js の planVisible の条件に「対象外でない」が入っていること。
